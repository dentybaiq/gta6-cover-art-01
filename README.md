# Vice Cover Studio — GTA 6 Cover Art Maker

Turn any photo and caption into GTA 6-style multi-panel cover art, offline in the browser.

Built for the [make.fun bounty](https://make.fun/bounty/gta6-cover-art-01).

## Run

Open `app/index.html` in a browser, or serve the folder:

```sh
node serve.ts
```

Pick a layout (Hero Duo, Four Up, Hero Strip), drop a photo into each panel, drag to pan, scroll to zoom, type a caption, and export a PNG in 1080×1080, 1080×1350, or 1920×1080.
